Things to know

No LLM needed. Without a local model it answers from extracted fields and keyword retrieval. An optional Ollama model, if you install one, gives more natural answers to open-ended questions. I could not test the Ollama path here, so check it on your machine if you plan to show it.
Field extraction is pattern-based. It works well on labelled lease wording like the samples; unusual layouts may show Not found.
Scanned PDFs are flagged No text found. OCR is not included.
